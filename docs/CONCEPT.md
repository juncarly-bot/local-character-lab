# Concept

## Goal

Local Character Labは、3B級のローカルLLMを使い、複数のキャラクターが同じ空間に存在しているように感じられる会話・生活シミュレーションを作るためのプロジェクトである。

単に「ユーザーが話す -> AIが答える」を繰り返すのではなく、キャラクター同士が互いの発言を聞き、関係性・興味・現在状態・欲求に応じて、自発的に話す、黙る、入室する、退出する、といった振る舞いを行う。

## Experience target

- ユーザーが不在でもキャラクター同士の会話が成立する
- いつ見ても全員が喋り続けるのではなく、沈黙も自然に存在する
- キャラクターごとに「知っていること」と「知らないこと」の差がある
- 誰と一緒にいるかによって、入室しやすさや会話内容が変わる
- 同じ話題でも、興味や価値観によってキャラクターごとの反応が変わる
- 前日の会話や出来事を、翌日の自発的な発言につなげられる

## Scope v1

- 共通3B級ベースモデル 1つ
- 登録キャラクター 最大10人程度
- 同時入室 最大4人
- 生活状態 `SLEEP` / `FREE`
- キャラクターごとのProfile
- 関係性システム
- 記憶システム
- 興味・価値観
- Mood
- 自発的欲求
- 入退室 / Presence Engine
- 新躍進政策のチャットUIを参考にした会話UI

## Integration policy

まず独立したCharacter Engineとして完成させ、その後に新躍進政策へ接続する。

新躍進政策側の学習状態・UsageStats・StudySession等の正規データはアプリ側が保持し、Character Engineは人格表現、会話、発言判断、関係性・記憶に基づく振る舞いを担当する方針とする。
